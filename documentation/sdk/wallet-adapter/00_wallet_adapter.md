The Aleo Wallet Adapter provides a standardized interface for integrating Aleo wallets into web applications.

For up-to-date documentation and examples, refer to the following resources:

- **[Wallet Adapter Documentation](https://aleo-dev-toolkit-documentation.vercel.app/docs/wallet-adapter)** — Full documentation covering installation, configuration, and API reference.
- **[Live Demo & React App](https://aleo-dev-toolkit-react-app.vercel.app/wallet)** — An interactive React application showcasing wallet adapter integration.
